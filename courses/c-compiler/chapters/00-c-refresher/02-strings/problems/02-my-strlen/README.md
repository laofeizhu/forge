Implement `strlen` yourself (don't call the library one):

```c
size_t my_strlen(const char *s);
```

Return the number of characters before the terminating `'\0'`.

**Example 1**
```
"hello"  →  5
```

**Example 2**
```
""       →  0
```

**Constraints**
- `s` is never NULL and is always terminated.
- Don't use `<string.h>`.
